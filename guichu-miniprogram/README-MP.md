# 知物寻迹 · 微信小程序版（v1.0.0 · 发布候选）

把「知物寻迹」（原名归处 · 空间记忆管家）的核心能力移植为**原生微信小程序**。与 `guichu-app/`（网页版）共享同一套数据模型设计。

> **正式发布**：照 [RELEASE.md](RELEASE.md) 清单走（注册账号 → 填 AppID → 后台三项配置 → 上传提审）。
> **发布门槛回归**：数据层/搜索/提醒/成员/备份/18 种表单共 39 项运行时测试全部通过（v1.0.0 前最后校验于 2026-11-02）。

## 如何运行

1. 下载并安装**微信开发者工具**（https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html ）
2. 打开开发者工具 → **导入项目** → 目录选择本文件夹 `guichu-miniprogram`
3. AppID 选择「**测试号**」（无需注册即可体验）；填了正式 AppID 就选自己的
4. 编译运行即可。真机预览：工具栏「预览」扫码

> 全新安装从**空白状态**开始（内置新手引导页 + 首页新手任务卡带领建房间/收纳点/物品）；「设置 → 清空全部数据」可重置回空白。

## 已实现功能

- **四级空间树**：住址（我的家/办公室/父母家，可增）→ 房间（增删改、主题色）→ 收纳点（增删改、五种视图类型）→ 物品（增删改、照片、重要级、权属、数量、效期、备注）
- **全景环视**：房间上传 2:1 全景照片（自动压缩存本机文件目录），横向滑动环视 + 热区点击进收纳点；收纳点方位角滑杆校准；无照片时用主题色底图
- **搜索**：名称/标签/备注/纸箱号 + **拼音全拼（yaoshi）/ 首字母（ys）+ 模糊容错（护昭→护照）**
- **场景化视图**：库存（数量±/效期进度条）、打卡（出门确认/复位）、档案（保密锁）、趣味（儿童大图标）
- **逻辑分区**：跨房间聚合，收纳点编辑中勾选归属
- **提醒中心**：效期临期 / 外借归还（可标记归还）/ 自定义周期盘点 / 库存补货
- **日程备物**：日程标题按关键词联想物品清单（离线规则引擎）
- **移动 + 位置历史**：物品移动自动记入历史
- **搬家打包**：按容器打包编号、箱内清单、开箱恢复、复制清单
- **应用锁**：可选 PIN（存哈希），锁屏数字键盘
- **连续录入**：保存后自动开下一条
- **数据导入导出**：完整备份 JSON（含照片 base64）通过聊天文件转发/导入

## 与网页版的能力差异（诚实对照）

| 能力 | 网页版 | 小程序版 v0.1 |
| --- | --- | --- |
| 球面全景 | ✅ 真实照片自动启用 | ⏳ 条带式先行（圆点标记支持“图上点一下”定位与四面拍摄拼接，小程序 WebGL 移植已预留） |
| 语音找物 | ✅ Web Speech | ⏳ 需接「微信同声传译」插件（路线图） |
| 地理围栏 | ✅ 定位 API | ⏳ 需 `wx.getLocation` + 后台权限声明（路线图） |
| NFC 写标签 | ✅ Web NFC | ⏳ 需小程序 NFC 接口（路线图） |
| 系统通知 | ✅ Notification | ⏳ 需微信「订阅消息」模板（见下） |
| 多人实时共享 | ⏳ 规划（WebDAV） | ⏳ 规划（微信云开发，更适合小程序） |

## 发布到线上的前提（对照检查清单）

1. 注册小程序账号（个人/企业主体），拿到正式 AppID 替换 `project.config.json` 里的 `touristappid`
2. **request 合法域名**：在小程序后台「开发管理 → 开发设置 → 服务器域名」加入你 AI 接口的域名（如 `https://open.bigmodel.cn`）；开发阶段在工具里勾选「不校验合法域名」即可
3. **类目审核**：工具类目一般选择「效率/备忘录」类
4. **订阅消息**：后台申请「到期提醒」模板，用 `wx.requestSubscribeMessage` 替代应用内提醒（代码预留于提醒中心说明）
5. 隐私：收集用户照片需在后台填写《用户隐私保护指引》

## 后续路线（小程序特有优势）

- **微信云开发**：数据同步 + 家庭共享的最佳路径（免自建服务器，云数据库 + 云函数，前端代码结构已按可迁移设计）
- **订阅消息**：到期/借还推送直达「服务通知」
- **微信同声传译插件**：语音找物
- **NFC**：`wx.getNFCReader` 读取标签直达物品
- **桌面小组件**：桌面端用网页版，手机端用小程序

## 已知限制

- 照片存本机文件目录，**换设备需走「导出备份 → 导入备份」**（备份含照片 base64）
- 长按语音、订阅消息、围栏、NFC、球面全景为路线图项（数据结构已预留）
- 本工程未经过真机全量回归，若个别 API 因基础库版本差异报错，调整 `project.config.json` 的 `libVersion` 即可
