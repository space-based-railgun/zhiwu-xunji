# 知物寻迹 —— 正式发布清单（v1.0）

> 零基础照着做即可。带 ⛔ 的步骤不做，小程序会审核不过或功能失效。

---

## 0. 先去注册正式小程序账号（免费）

1. 打开 mp.weixin.qq.com → 「立即注册」→ 选「小程序」。
2. 用一个**没注册过公众号/小程序的邮箱**，个人主体：填身份证 + 手机号，管理员是你自己的微信。
3. 注册完登录后台，左侧「设置 → 基础设置」里能看到 **AppID（wx 开头）**，复制下来。

> 个人主体免费、每年可发布；名字填「知物寻迹」，若重名了换近似名并在代码里同步改。

## 1. 项目接入 AppID

开发者工具打开本项目 → 右上角「详情」→「基本信息」→ AppID 处点「修改」，填入你的 AppID。
（等价做法：把 project.config.json 里的 `"touristappid"` 换成你的 AppID。）

## 2. ⛔ 后台必须配置的三件事

| 事项 | 位置 | 说明 |
|---|---|---|
| 用户隐私保护指引 | 后台「设置 → 服务内容声明 → 用户隐私保护指引」 | ⛔ 勾选**摄像头、相册（仅写入权限也要勾）**、剪贴板。不配置，真机拍照/选图接口直接被微信拒绝 |
| request 合法域名 | 后台「开发 → 开发管理 → 开发设置 → 服务器域名」 | request 合法域名填 `https://open.bigmodel.cn`（AI 识别用）。⛔ 不配置，正式版 AI 识别全部请求失败 |
| 服务类目 | 后台「设置 → 基本设置 → 服务类目」 | 选 **工具 → 效率**（个人主体可选） |

配置完域名后：开发者工具「详情 → 本地设置」**取消勾选**「不校验合法域名」，再完整测一遍 AI 拍照识别。

## 3. AI 免费接入（已实现，无月费）

模型用的是智谱 **glm-4v-flash（官方免费模型，调用不扣费）**。v1.0 起**代码里不内置任何 Key**（防止发布后被提取盗刷），新用户走 30 秒自助引导：

- 点任意 AI 入口 → 弹「开启 AI 识别（免费）」教程 → 「去配置」；
- 配置表单里提供「📋 复制注册网址」「📥 读取剪贴板 Key」两个一键按钮，注册 → 复制 → 粘贴即完成。

每个用户管理自己的 Key，你零成本、零风险。后期若想做到"用户零操作"，再升级云函数代理（个人版约 19.9 元/月，可随时取消；Key 藏服务端全家共用），结构已预留（AI_DEFAULT + OpenAI 兼容格式，换地址即可）。

## 4. 上传 → 提审 → 发布

1. 开发者工具右上角「**上传**」→ 版本号填 `1.0.0`，备注写「首个正式版」。
2. 后台「版本管理」→ 开发版本右侧「**提交审核**」→ 按提示填功能页面说明（选首页截图即可）。
3. 等审核（个人号常见 1-2 天，最长 7 天）。通过后回「版本管理」点「**发布**」。
4. 发布后用户在微信里搜小程序名字即可使用；家人先加「体验版」（版本管理 → 体验版二维码）更方便。

## 5. 提审前自查

- [ ] 换正式 AppID 后真机完整走一遍：选人登录 → 建房间 → AI 拍照建收纳点 → AI 拍照入库 → 搜索 → 提醒顺延 → 备份导出
- [ ] 关闭「不校验合法域名」后 AI 识别仍正常
- [ ] 引导页、新手上路任务卡、成员 PIN 切换正常
- [ ] 深色模式（手机系统深色）下界面可读
- [ ] 「设置 → 关于」显示 v1.0

## 6. 审核被拒的常见原因与话术

- 「未提供隐私指引」→ 回到 2 表第 1 项，勾全再提审。
- 「类目不符」→ 换 工具→效率 或 生活服务。
- 「功能简介不清」→ 审核备注里写：「一款本地记录家庭物品位置的工具：拍照建档、按拼音搜索、到期提醒，数据仅存本机。」
