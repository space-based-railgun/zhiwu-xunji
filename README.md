# 知物寻迹（原名：归处 · 空间记忆管家）

找不到东西的时候，3 秒查到它在哪。给住址 → 房间 → 柜子 → 物品建立一本「活地图」：拍照建档、拼音搜索、到期提醒、外借记录、搬家打包。

## 仓库结构

| 目录 | 说明 |
|---|---|
| `guichu-miniprogram/` | 微信小程序版（主力版本） |
| `guichu-app/` | 网页版（纯前端，浏览器直接可用） |
| `guichu-cloud/` | 云开发服务端（可选：AI 服务端代理 / openid 绑定 / 数据同步） |

## 功能一览

- 空间树：住址 / 房间 / 收纳点 / 物品 四级管理
- 全景定位：四面拍摄自动拼接环视图，柜子以圆点标记在图上
- AI 拍照入库：拍房间照片自动建收纳点、拍柜内照片自动认物品（glm-4v-flash 免费模型）
- 搜索：中文名 / 拼音（yaoshi）/ 口语说法（"充电的东西"）/ 近似名称
- 提醒：到期（药品/食品）、外借归还、库存补货、自定义周期盘点
- 成员账户：本机多人身份 + 可选 PIN + 微信头像昵称绑定
- 搬家打包：整柜装箱、逐箱开箱、位置历史
- 备份：手动导出/导入（含照片），本地自动滚动备份防损坏
- 新手引导：首次启动引导页 + 首页新手任务卡

## 运行小程序版

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入 `guichu-miniprogram/` 目录，填入自己的 AppID（或先用测试号）
3. AI 拍照功能需在「设置 → AI 识别配置」填入自己的智谱 API Key（[open.bigmodel.cn](https://open.bigmodel.cn) 免费注册，glm-4v-flash 模型免费）

## 运行网页版

双击 `guichu-app/启动.bat`，或在该目录下起任意静态服务器（如 `python -m http.server 8080`）后浏览器访问。

## 云开发（可选）

见 `guichu-cloud/README.md`。

## 数据与隐私

所有用户数据仅存于设备本地（结构数据 + 照片），不上传任何服务器；云开发目录为可选项，默认未启用。
