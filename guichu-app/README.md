# 归处 · 空间记忆管家（本地完整版）

一个**零依赖、可离线运行**的纯前端应用：管理"东西放在哪"，用全景环视 + 热区 + 搜索定位，告别翻箱倒柜。所有数据只存在你自己的浏览器里，不经任何服务器。

## 如何运行

**方式一（最简单）**：双击 `启动.bat`（自动启动服务并打开浏览器），或双击 `index.html` 用 Chrome / Edge 打开。

**方式二（功能最全）**：在本目录启动本地服务后访问：

```bash
py -m http.server 8080        # Windows（Python 启动器）
python -m http.server 8080    # 通用
npx serve .                   # Node.js
```

浏览器打开 `http://localhost:8080`。

> 双击 `index.html`（file:// 方式）时基础功能全部可用；PWA 安装、Service Worker、地理围栏需要 http(s) 环境，推荐用 `启动.bat`。

## 数据与隐私（v1.1 存储架构）

- **结构数据**（空间树、提醒、设置）存浏览器 `localStorage`，小而快。
- **照片与全景**存浏览器 `IndexedDB`（容量以百 MB 计），上传时自动压缩：全景最长边 1600px、物品照 640px。
- 旧版本内联在结构数据里的照片，**首次打开新版时自动迁移**到 IndexedDB，无需手工处理。
- 被删除物品的照片会被自动回收（孤儿清理），不会越积越多。
- 任何数据都不上传服务器；清除浏览器站点数据 = 清空应用，请定期「导出完整备份」（备份文件内含全部照片，换设备导入即可整体搬家）。

## 通知能力边界（诚实说明）

系统通知需要应用处于运行状态（打开的标签页 / 已安装的 PWA 窗口），应用打开期间每 30 分钟检查一次到期情况并推送。**完全关闭应用后的离线推送**需要推送服务器，属于后续路线图（可接 WebDAV 自定义同步一并解决）。

## 二次开发提示

- **接入真实 AI 识别**：在 `app.js` 的 `openItemModal` 流程中，把照片 dataURL POST 给多模态模型 API，用返回的名称/类别预填表单即可。
- **接入真实全景**：`room.panoId` 指向 IndexedDB 中的任意 equirectangular 图，上传后自动启用 WebGL 球面渲染（`pano.js`）。
- **多人同步**：数据层是纯 JSON（`Store.buildBackup()`，已含图片），接一个带鉴权的云存储即可实现家庭共享。
- **图片存储 API**：`Store.putImg(dataURL)` 返回图片 id（同步入缓存、异步落盘）；`Store.imgSrc(id)` 同步取值；`Store.preloadImages(cb)` 启动预加载；孤儿回收随每次保存自动运行。
- **拼音表扩充**：`store.js` 顶部 `PYS` 表按读音组织常用字，缺失的字按读音补进去即可（多音字放进最常用的读音组）。
- **AI 识别**：`aiIdentify()` 已按 OpenAI 兼容格式发图，换任何多模态服务只需改 `db.ai.url`；提示词在函数内，可按需调整返回字段。
